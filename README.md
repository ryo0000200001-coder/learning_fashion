# Archive Notes — 古着とデザイナーの学習帳

デザイナーズ古着・アーカイブを理解するために、国内（ドメスティック）／海外（インポート）ブランドの
**歴史・デザイナーの変遷・代表的なアイテム**を学ぶための個人サイトです。

## 機能

| ページ | 内容 |
| --- | --- |
| ブランド | 検索・国内/海外・タグで絞り込み。詳細ページに年表、デザイナー変遷バー、シーズン一覧、代表アイテム、古着で見るポイント、出典 |
| デザイナー | デザイナーごとの経歴。前任・後任へのリンクでブランド間のつながりをたどれる |
| 変遷年表 | 全ブランドのデザイナー在任期間をガントチャート表示。同じデザイナーは同じ色 |
| シーズン索引 | 「2004-05AW」「SCAB」「カート期」などのシーズン表記・タイトル・通称からコレクションを引ける |
| 用語集 | アーカイブ、アントワープ・シックス、裏原宿などの基本用語 |

各ブランドページで「学習済み」チェックと自分用メモが使えます（ブラウザの localStorage に保存）。

## 使い方

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで見る場合:

```bash
python3 -m http.server 8000
```

### GitHub Pages で公開する

リポジトリの Settings → Pages → Branch を選んで Save するだけで公開できます（`.nojekyll` 同梱）。

## データの追加・編集

すべての内容は `data/` フォルダの JavaScript ファイルにあります。

- `data/designers.js` — デザイナー辞書（キー、英語名、日本語名、メモ）
- `data/brands.js` — ブランド（歴史、デザイナー在任、アイテム、アーカイブのポイント）
- `data/glossary.js` — 用語集

ブランドを追加する例:

```js
{
  id: "newbrand", name: "Brand Name", ja: "ブランド名",
  origin: "domestic",            // 国内なら "domestic"、海外なら "import"
  country: "日本", city: "東京", founded: 2000,
  tags: ["モード", "メンズ"],
  summary: "概要",
  history: [ { year: 2000, text: "設立" } ],
  designers: [ { d: "designerKey", role: "デザイナー", from: 2000, to: null } ], // to: null は現在
  items: [ { name: "代表アイテム", year: 2005, desc: "説明" } ],
  archive: [ "古着で見るときのポイント" ],
  related: ["cdg"]
}
```

`designers[].d` には `data/designers.js` のキーを使います。新しいデザイナーは先に辞書に追加してください。
デザイナー一覧、年表、シーズン索引はデータから自動で作られます。

シーズンを追加するときは `collections: [{ season: "2003SS", title: "SCAB", city: "パリ", alias: "通称", note: "メモ" }]` の形で書きます。裏付けが取れない項目には `unverified: true` を付けると「未確認」と表示されます。出典は `sources: [{ t: "タイトル", u: "URL" }]` に書きます。

## 注意

内容は2026年11月時点でウェブ上の資料と照合し、各ブランドに出典を載せています。
裏付けが取れなかった項目は「未確認」、資料どうしで食い違う点は各ブランドの注記に書いています。
デザイナーの体制は頻繁に変わるので、定期的に見直してください。
