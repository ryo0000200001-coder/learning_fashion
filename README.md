# Archive Notes — 古着とデザイナーの知識帳

デザイナーズ古着・アーカイブについての自分用の知識帳です。国内（ドメスティック）／海外（インポート）ブランドの
**歴史・デザイナーの変遷・ライン・シーズン・代表的なアイテム**をまとめています。
アルチザン系（Carol Christian Poell、Guidi、m.a+ など）も収録しています。

## 機能

| ページ | 内容 |
| --- | --- |
| ホーム | ブランド・デザイナー・ライン・アイテム・シーズン・用語の横断検索と、国内／海外のブランド索引 |
| ブランド | 検索・国内/海外・タグ（ジャンル）で絞り込み。詳細ページに年表、デザイナー変遷バー、シーズン一覧、代表アイテム、古着で見るポイント、出典 |
| デザイナー | デザイナーごとの経歴。前任・後任へのリンクでブランド間のつながりをたどれる |
| 変遷年表 | 全ブランドのデザイナー在任期間をガントチャート表示。同じデザイナーは同じ色 |
| シーズン索引 | 「2004-05AW」「AW04」「SCAB」「カート期」などのシーズン表記・タイトル・通称からコレクションを引ける |
| 用語集 | アーカイブ、アルチザン、アントワープ・シックス、裏原宿などの基本用語 |
| ✎ 編集 | ブランド・デザイナー・用語をサイト上で追加・修正し、GitHub に保存できる |

各ブランドページの下に自分用メモ欄があります（そのブラウザにだけ保存されます）。

## 使い方

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで見る場合:

```bash
python3 -m http.server 8000
```

### GitHub Pages で公開する

1. リポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」にし、公開したいブランチ（例: `main`）と `/ (root)` を選んで Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

`.nojekyll` を同梱しているので、そのまま配信されます。

## サイト上で編集する

画面右上の「✎ 編集」から、ブランド・ライン・デザイナー・用語集を追加・修正できます。ブランドページでラインを開くと「このラインを編集」から、そのラインの歴史・名作シーズン・名作アイテムを直せます。各ブランドページやデザイナーページの「✎ 編集」ボタンからも直接開けます。

### 流れ

1. 編集画面で内容を直し「保存（下書き）」を押す → **このブラウザに下書きとして保存**され、すぐサイトに反映して見える（自分のブラウザだけ）
2. 編集トップ（`#/edit`）で変更の説明を書いて「GitHubに保存」を押す → `data/*.js` がリポジトリにコミットされる
3. GitHub Pages が再構築されると（1〜数分）、どの端末から見ても新しい内容になる

下書きは「下書きを破棄」で取り消せます。GitHub に保存した後の取り消しは、GitHub 上のコミット履歴から戻せます。

### 最初に一度だけ：GitHub トークンの設定

「GitHubに保存」には、このリポジトリにだけ書き込める **Fine-grained personal access token** が必要です。

1. GitHub の Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. Repository access で **Only select repositories** を選び、このリポジトリだけを選ぶ
3. Repository permissions の **Contents** を **Read and write** にする（他の権限は不要）
4. 作成されたトークンをサイトの「設定」（`#/settings`）に貼り付け、「接続テスト」で確認
5. 保存先のブランチは `main`（GitHub Pages で公開しているブランチ）。別のブランチで公開する場合だけ設定で変更する

トークンはそのブラウザの localStorage にだけ保存され、GitHub の API 以外には送られません。共用のパソコンでは登録しないでください。

トークンを使わない場合は、編集トップの「ファイルを書き出す」で `brands.js` / `designers.js` / `glossary.js` をダウンロードし、GitHub の画面から `data/` にアップロードしても同じ結果になります。

### 別の場所で同時に編集した場合

保存の直前に GitHub 上のファイルを確認し、このブラウザで編集を始めた後に別の場所（別の端末や GitHub の画面）で変更されていた場合は、上書きしてよいか確認が出ます。

## データの形式

すべての内容は `data/` フォルダにあり、`window.XXX = <JSON>;` の形で保存されています（編集画面が読み書きするため、手で直すときも JSON の形を崩さないでください）。

- `data/designers.js` — デザイナー辞書（キー → `{ en, ja, bio }`）
- `data/brands.js` — ブランドの配列
- `data/glossary.js` — 用語集の配列

ブランドの項目:

| 項目 | 内容 |
| --- | --- |
| `id` | URLに使うID（半角小文字英数字とハイフン） |
| `name` / `ja` | ブランド名 / 読み |
| `origin` | `"domestic"`（国内）または `"import"`（海外） |
| `country` / `city` / `founded` | 国 / 拠点 / 創業年 |
| `tags` | タグ（「アルチザン」などのジャンルもここ） |
| `summary` / `note` | 概要 / 注記（資料の食い違いなど） |
| `history` | `[{ year, text, unverified? }]` 年表 |
| `designers` | `[{ d: デザイナーのキー, role, from, to }]`（`to: null` は現在） |
| `collections` | `[{ season, title, city, alias, note, unverified? }]` シーズン一覧 |
| `lines` | `[{ name, from, to, designer, desc, history, collections, items, archive, unverified? }]` ブランド内のライン。歴史・名作シーズン・名作アイテム・古着のポイントをライン単位で持てる |
| `items` | `[{ name, year, desc, img, credit, license, imgPage, unverified? }]` 代表的なアイテム（写真は任意） |
| `archive` | 古着・アーカイブで見るポイント（文字列の配列） |
| `related` | 関連ブランドの `id` |
| `sources` | `[{ t: タイトル, u: URL }]` 出典 |

`unverified: true` を付けた項目は画面に「未確認」と表示されます。デザイナー一覧、年表、シーズン索引はデータから自動で作られます。

## 注意

内容は2026年11月時点でウェブ上の資料と照合し、各ブランドに出典を載せています。
裏付けが取れなかった項目は「未確認」、資料どうしで食い違う点は各ブランドの注記に書いています。
デザイナーの体制は頻繁に変わるので、定期的に見直してください。
